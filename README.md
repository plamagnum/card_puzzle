# Geo Puzzle School

Geo Puzzle School — це навчальний fullstack вебзастосунок для 5–11 класів, у якому учні складають географічні пазли в командах та змагаються за першість.

## Що реалізовано

- nginx + PHP-FPM + MySQL + phpMyAdmin через Docker Compose
- спрощена реєстрація учня за ім’ям і класом
- дві команди з автоматичним розподілом учнів та ручним коригуванням адміністратором
- ролі **учень** та **адміністратор**
- кілька рівнів пазлів для різних географічних об’єктів: материк, острів, озеро, океан
- drag & drop пазлів мишею та пальцем через Pointer Events
- блокування раунду після першої перемоги з показом імені переможця та команди
- старт нового раунду адміністратором
- CRUD задач користувача та повне керування задачами адміністратором
- дашборд результатів з перемогами команд, ТОП учнів та історією раундів
- технічна статистика для адміністратора: IP, user-agent, ОС, браузер, пристрій, маршрут, метод запиту
- темна/світла тема
- mobile-first адаптивний інтерфейс

## Структура проєкту

- `docker-compose.yml` — опис сервісів
- `docker/nginx/default.conf` — конфігурація nginx
- `docker/php/Dockerfile` — PHP-FPM образ з `pdo_mysql`
- `docker/mysql/init/01-schema.sql` — схема MySQL
- `public/` — вебкорінь з PHP, CSS, JS та SVG-картками
- `src/` — конфігурація, авторизація, допоміжні функції

## Покроковий запуск

1. Встановіть Docker та Docker Compose.
2. Відкрийте термінал у каталозі репозиторію:
   ```bash
   cd /home/runner/work/card_puzzle/card_puzzle
   ```
3. Запустіть контейнери:
   ```bash
   docker compose up --build
   ```
4. Дочекайтесь ініціалізації MySQL та відкрийте:
   - застосунок: `http://localhost:8080`
   - phpMyAdmin: `http://localhost:8081`
5. Для входу адміністратором використайте:
   - логін: `admin`
   - пароль: `admin12345`
6. Учень входить через форму швидкої реєстрації, вказавши ім’я та клас.
7. Адміністратор запускає новий раунд через блок **Керування раундами**.
8. Учні складають пазл. Після першої перемоги раунд блокується, а адмін запускає наступний.

## Як працює гра

1. Учень реєструється або повторно входить за ім’ям та класом.
2. Система автоматично додає його до меншої за кількістю команди.
3. Адміністратор запускає раунд з одним із заготовлених географічних пазлів.
4. На сторінці учня з’являється ігрове поле та перемішані фрагменти.
5. Коли всі фрагменти встановлені на свої місця, результат відправляється на сервер.
6. Сервер атомарно визначає першого переможця, фіксує його команду та завершує раунд.

## Робота з базою даних

- база: `card_puzzle`
- користувач застосунку: `app_user`
- пароль застосунку: `app_password`
- root-користувач MySQL: `root`
- root-пароль MySQL: `root_password`
